تفعيل ADB / Root وتخطي FRP على أجهزة Samsung Exynos — كل شيء في أداة واحدة

v1.3.0 — يدعم نووي Exynos 7570 → 2500 · مع FRP ADB

ما هي الأداة؟

YAZ adb أداة وندوز موحدة — تفعيل ADB / Root من وضع Download (Odin) عبر استغلال CPDN (captured_live)، وتخطي FRP عبر ADB في نفس الواجهة. كل شيء يمر عبر نفس التيرمنال، بضغطة واحدة يقرأ معلومات جهازك (سيريال، IMEI، الموديل، المنفذ) ويعرضها فوراً.

منذ 1.3.0: زر FRP ADB بجانب تفعيل ADB، قراءة تلقائية فور فتح الأداة بدون طلب سيريال، ونسخ من التيرمنال بالكليك اليمين بدون تسجيل.

ميزة FRP ADB الجديدة

بعد تفعيل ADB، يبقى الجهاز في ADB — اضغط FRP ADB ليكتب Frp.bin على بارتشن persistent / frp عبر adb push + dd ثم يعيد التشغيل. نفس السيريال المسجل يعمل للـ ADB والـ FRP.

الملفات المضمنة: adb.exe + AdbWinApi.dll + AdbWinUsbApi.dll + Frp.bin — لا تحتاج تثبيت خارجي.

لماذا أحتاج سيريال؟

الأداة مشفّرة وترخيصها مرسوم على سيريال جهازك. قبل التفعيل يجب تسجيل السيريال عبر صفحة التسجيل، ثم إدخاله في الحقل والتحقق منه — الأداة تتصل بالخادم وتتحقق. بدون سيريال موثّق لن يبدأ التفعيل.

بعد الضغط على زر (تفعيل ADB) بدون سيريال، تظهر رسالة «قم بتسجيل السيريال اولا» ويُنسخ سيريال جهازك تلقائياً إلى الحافظة لتسليمه في صفحة التسجيل — ثم ألصقه في الحقل وأعد الضغط.

كيف تستعمل — خطوة بخطوة

  1. Windows فقط + شغّل كمسؤول (الأداة تطلب UAC تلقائياً).
  2. حمّل YAZ adb.exe وشغّله — يفحص التحديث ثم يقرأ معلومات جهازك تلقائياً ويعرض السيريال/IMEI/الموديل/المنفذ في التيرمنال بدون طلب تسجيل.
  3. لـ ADB: أطفئ الهاتف، اضغط خفض + رفع الصوت مع الكابل لدخول Download ثم رفع الصوت، اختر المعالج (أو Auto)، أدخل السيريال واضغط تفعيل ADB — يدخل COMPELSON RECOVERY مع ADB جذر.
  4. لـ FRP: بعد تفعيل ADB وإعادة التشغيل للوضع العادي (مع USB Debugging)، اضغط FRP ADB بجانب زر التفعيل — يكتب Frp.bin ويعيد التشغيل.
  5. لنسخ أي سطر من التيرمنال: كليك يمين → نسخ السيريال / نسخ معلومات الجهاز / نسخ التحديد — لا يطلب تسجيلاً.
  6. زرا تفعيل ADB و FRP ADB بجانب خانة السيريال — كل شيء عبر نفس التيرمنال.

معلومات إضافية

عند قراءة معلومات الجهاز (تلقائياً عند الفتح) يظهر: السيريال أولاً ثم IMEI ثم الموديل والمنفذ وحرف الحماية والوضع وأدق تفاصيل المعالج: BASE, OFFSET, VARIANT, CPDN USB, STATUS — كلها في التيرمنال وقابلة للنسخ.

المنفذ: يُكتشف تلقائياً — إن وجد COM يظهر، وإلا يعمل عبر USB مباشر (libusb) بدون الحاجة لمنفذ. الأداة تتعامل مع الحالتين تلقائياً.

مشاكل وحلول

❌ يظهر «Unsupported device»: لا يوجد ملف تفعيل لمعالجك — جهازك خارج القائمة.

❌ يرفض المحرك «invalid execution context»: شغّل الأداة كمسؤول (تطلب UAC تلقائياً) وتأكد من السيريال.

❌ لا يجد منفذ COM: لا مشكلة — الأداة تعمل عبر USB مباشر تلقائياً.

❌ تفعيل/FRP فشل برغم الجهاز مدعوم: كابل أصلي، منفذ USB خلفي، وضع Download (لـ ADB) أو ADB مصرح (لـ FRP)، وسيريال مسجّل.
